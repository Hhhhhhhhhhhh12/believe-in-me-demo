# Believe in Me: Browser Demo

Static browser demo. This export command itself never deploys or pushes.

The Python rules engine runs locally in a Pyodide Web Worker. No Python server is required. Serve this directory over HTTP(S), not file://. Paths are relative for a project subdirectory.

New mini-matches start with 6 believers. Existing six- and twelve-believer command histories retain their original setup. Progress is stored per browser tab; display settings are stored in this browser.

The engine and selected original artwork are downloaded to the client. There is no password protection; opponent hands are hidden by the UI, not protected against developer tools.

Readable engine sources and selected data are in source/. The web sources are at the root. No Git history, login server, credentials or private deployment documents are included.

Original graphics and rules-engine inclusion were approved by the owner. No new general reuse licence is assigned by this export. Third-party components retain their own terms; see THIRD_PARTY_NOTICES.md.

Accessibility review is in progress. This demo is not an accessibility certification; remaining VoiceOver checks and physical-phone review are documented as incomplete. No automatic publishing workflow is included.
